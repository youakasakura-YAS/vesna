# Golden Baseline

This directory is the authoritative baseline for line-by-line conformance of the C++ implementation.

- `regression.out` / `fs_test.out` / `smoke04.out`: generated by the frozen **Python reference implementation 1.0.0** (youakasakura-YAS/vesna-py), which is kept only for regression.
- `examples/*.out`: generated by the **C++ implementation** (authoritative), because after the Python implementation was frozen, `#fread` + `#len` semantics differ (Python counts characters, C++ counts UTF-8 bytes).
- `concurrency.out` / `binary.out` (since 1.1): generated by the **C++ implementation only** — these builtins do not exist in the frozen Python reference.

## Regeneration commands

```bat
set PYTHONIOENCODING=utf-8
set VESNA_HOME=repo root

cd src\cpp
python repo-root\src\vesna.py tests\regression.ves > tests\golden\regression.out
python repo-root\src\vesna.py tests\fs_test.ves    > tests\golden\fs_test.out
python repo-root\src\vesna.py tests\smoke04.ves    > tests\golden\smoke04.out

rem 1.1 builtins (C++ only)
repo-root\bin\vesna.exe tests\concurrency.ves > tests\golden\concurrency.out
repo-root\bin\vesna.exe tests\binary.ves      > tests\golden\binary.out

cd examples
repo-root\bin\vesna.exe csv2json.ves sample.csv          > ..\src\cpp\tests\golden\examples\csv2json.out
repo-root\bin\vesna.exe cut.ves "," "2" sample.csv       > ..\src\cpp\tests\golden\examples\cut.out
repo-root\bin\vesna.exe extract.ves sample.txt           > ..\src\cpp\tests\golden\examples\extract.out
repo-root\bin\vesna.exe grep.ves "ERROR" sample.txt      > ..\src\cpp\tests\golden\examples\grep.out
repo-root\bin\vesna.exe head.ves "3" sample.txt          > ..\src\cpp\tests\golden\examples\head.out
repo-root\bin\vesna.exe logstat.ves sample.txt           > ..\src\cpp\tests\golden\examples\logstat.out
repo-root\bin\vesna.exe replace.ves "a" "X" sample.txt   > ..\src\cpp\tests\golden\examples\replace.out
repo-root\bin\vesna.exe sed.ves "\d+" "N" sample.txt     > ..\src\cpp\tests\golden\examples\sed.out
repo-root\bin\vesna.exe sort.ves sample.txt              > ..\src\cpp\tests\golden\examples\sort.out
repo-root\bin\vesna.exe stat.ves sample.txt              > ..\src\cpp\tests\golden\examples\stat.out
repo-root\bin\vesna.exe tail.ves "3" sample.txt          > ..\src\cpp\tests\golden\examples\tail.out
repo-root\bin\vesna.exe uniq.ves sample.txt              > ..\src\cpp\tests\golden\examples\uniq.out
repo-root\bin\vesna.exe wc.ves sample.txt                > ..\src\cpp\tests\golden\examples\wc.out
```

**Notes**:
- Redirecting output to a file requires `PYTHONIOENCODING=utf-8` to match the C++ UTF-8 output.
- `fs_test.ves` creates and self-cleans temporary files; cwd must be `src\cpp` when generating its golden.
- Regenerate this directory only when the authoritative implementation semantics change.
